# Vargas Tech

Adaptación académica de Zay Shop (TemplateMo 559) con temática de tecnología, preparada para Tiago Vargas.

Sitio estático: abrir `index.html` o servir la carpeta con Apache/XAMPP. No requiere dependencias adicionales ni compilación. Compatible con despliegue en una subcarpeta, GitHub Pages y Netlify.

## Funciones

- Cinco páginas en español y diseño adaptable.
- Ocho productos ilustrados, búsqueda, filtros y ordenación.
- Ficha individual de producto.
- Selección persistente en localStorage, cantidades y total.
- Cotización descargable como texto.
- Consulta validada y descargable localmente.

Los productos, especificaciones y precios son ficticios. No hay pagos, compras reales ni envío de mensajes a un servidor.

## Editar

- `assets/js/products.js`: catálogo, nombres, precios, especificaciones.
- `assets/css/custom.css`: diseño y colores.
- `assets/js/custom.js`: interacciones y almacenamiento.
- `assets/img/`: ilustraciones SVG.
- Archivos HTML: contenido de cada página.

Base: [Zay Shop de TemplateMo](https://templatemo.com/tm-559-zay-shop), con Bootstrap y su hoja de estilos base. Se mantienen los créditos en el sitio y los encabezados de las bibliotecas distribuidas.
